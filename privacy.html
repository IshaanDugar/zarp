Who we are

Zarp is free software made by Ishaan, an individual based in Singapore ("the developer", "we"). Contact for privacy questions, access, correction, withdrawal and deletion: ishaandugar@u.nus.edu.

The short version

  • Your files and the search index stay on your computer. Zarp reads your files and never changes them.
  • By default Zarp sends the developer usage numbers tied to a random install ID (counts, timings, error codes). It does not send your questions, file names or text from your documents unless you switch on "Share full details".
  • If you connect an AI app, the passages Zarp finds for that app are given to that app and then go to that app's company. That is outside Zarp's control.
  • Zarp checks GitHub for updates and the date.

What Zarp collects and why

1. Usage reports (default: counts only) [A]

  • What: a random install ID (a random number made when you first run Zarp, not linked to your name, email, account or computer name), the Zarp version, and numbers and codes: how long searches took, how many results, which kind of file type came first (for example "pdf"), error codes, the size and speed of your computer in numbers (CPU count, memory, free disk space, screen size), how many files were read, and the name of a connected AI app from a fixed list. For each question it sends the question's length and a scrambled fingerprint (a salted hash) made with a random key that Zarp throws away when it closes. The developer cannot turn the fingerprint back into your question, and cannot match the same question across separate runs.
  • What it does not send in this mode: your questions, file names, folder names, file paths, text from your documents, your computer name, operating-system text, CPU model, language setting, or the text of error messages.
  • Purpose: to fix bugs, measure speed and reliability, and decide what to improve.
  • Like any internet connection, the server receiving the report can see your IP address at that moment. [OWNER CHECK: whether the server keeps IP logs and for how long.]
  • You can switch these reports off at any time in Settings > Privacy ("Send anonymous usage counts"). When they are off, Zarp records and sends nothing, and any unsent reports on your computer are deleted.

2. "Share full details" (optional, off by default) [A5]

You can turn it on in Settings > Privacy. If you do, Zarp can also send: the text of your questions (up to 2,000 characters), file names and cleaned file paths of top results (your folder's name plus the path inside it; the rest of the path is removed), the passages (text from your documents) that an AI app received, the notes you give in the feedback tool, error messages, operating system, CPU model, language setting and similar details. Anything sent in this mode can include personal information that is in your files, questions or file names. Turn it on only if you are comfortable with that.

  • Purpose: to understand and fix wrong or missed answers.
  • Turn it off at any time in Settings. Rows still waiting on your computer are cut down to counts-only straight away. Rows already sent are not recalled; see "Deleting your data".
  • Safety brake: a signed update message from the developer can reduce or stop the detailed rows centrally. It cannot switch on anything you have not allowed.

3. Written feedback [A6]

Star ratings are sent as numbers. Your written comment is sent only if you tick "Send my written comment too" for that comment, or you have turned on Share full details. Paths in the comment are cleaned, and it is cut at 4,000 characters. Your AI app can also send feedback through Zarp's feedback tool when you ask it to; in default mode only the verdict (for example "wrong answer") and counts are sent, not your note or document text. When usage reports are off, no ratings, verdicts or written comments are uploaded.

  • Purpose: to read what you tell us and improve Zarp.

4. Update checks and the date check [B]

Zarp asks GitHub for a small update file about every 6 hours and at startup. It sends only the Zarp version in the request's user-agent text and the ordinary information any web request carries (your IP address). It does not send your install ID. If it cannot get the date from that file, it asks github.com for the date. When a new version is available, Zarp can download the installer from the address in that file, check it against a fingerprint, and run it. The update file can also set a minimum version; if your version is older than that minimum, search stops until you update. GitHub's own terms and privacy statement apply to its servers.

5. Search model download [C]

Zarp's search model is [OWNER CHECK: bundled in the installer / downloaded on first run]. If it is downloaded, it comes from huggingface.co, which will see your IP address; their terms apply.

6. Connected AI apps [D]

When you connect an AI app (for example Claude, ChatGPT/Codex, Cursor or Gemini CLI), that app can ask Zarp to search the folders you shared. Zarp returns passages of your files, with file name, folder name and page or slide, to that app. The app then handles the text under its own company's terms and privacy policy, which may include sending it to that company's servers and storing it. Zarp does not control this. Share only folders whose content you are happy for that AI app to receive. You can change the shared folders in Zarp and disconnect an app at any time. Connecting adds a Zarp entry to that app's own settings file; disconnecting removes it.

What stays on your computer [E]

In %LOCALAPPDATA%\DiskAI-Beta (Windows) or ~/Library/Application Support/DiskAI-Beta (macOS): the search index, which includes the readable text of the files you chose, their paths and names, and number vectors; your settings, including your shared folders; unsent usage-report rows; the install ID; a local record of results you opened or pinned (with your search words); totals for the Analytics page; a log file of warnings and errors; downloaded updates and model files. You may withdraw consent for optional items at any time (turn off Share full details, do not tick the comment box, disconnect an AI app, uninstall). Withdrawing does not undo past lawful use. To stop all usage-report collection and uploads, turn off Send anonymous usage counts in Settings > Privacy. [LAWYER CHECK: PDPA consent and deemed-consent wording.]

Access, correction and deletion

  • The usage data we hold is linked only to the install ID. Zarp's Settings > Help > "Copy my support ID" copies it. Email ishaandugar@u.nus.edu with that ID and tell us what you want (a copy, correction or deletion). We aim to reply within [30] days. Without your install ID we cannot find rows. [OWNER CHECK: confirm deletion by install ID is possible on the server and who does it.]
  • Reports are structured numbers, so "correction" usually means deletion.
  • Local data: quit Zarp, uninstall it (Windows Settings > Apps > Installed apps > Zarp > Uninstall; on macOS remove Zarp.app), then delete the data folder named above to remove the index, settings and queue. Deleting that folder also removes the install ID (a new one is made if you reinstall). Your original files stay where they were. Autostart and AI-app entries: switch off "Open Zarp when I log in" and disconnect the AI app in Zarp first, or remove the Zarp entry in that app's settings. [OWNER CHECK: confirm that uninstall also removes the autostart entry and the AI-app entries; the code review did not trace the uninstaller.]

How long we keep data

  • On your computer: until you delete the data folder. Unsent report rows are capped at 20 MB per queue file, oldest dropped first.
  • On the server: up to 24 months, then deleted. Reports already sent before you switched them off are kept until then unless you ask us to delete them sooner (see above).

Reports are sent over HTTPS with certificate checks. Free-text and path fields are cleaned of absolute paths before sending. The upload key shipped in the app is a public client key; access rules on the server decide what it can do.
